Line Break Variants

These sections isolate the line-break and blank-line encodings we tested on plain pre blocks.

Variant: pre_br_nbsp

Expected source shape: plain pre with explicit line breaks and non-breaking space for empty lines.

def pattern_two():
    first = 1

    second = 2
    return first + second

Variant: pre_br_empty

Expected source shape: plain pre with explicit line breaks and truly empty blank lines.

def pattern_seven():
    rows = []
    for index in range(20):
        rows.append({
            "marker": "PATTERN-07-CODE",
            "index": index,
            "value": index * 3,
        })
    return rows

result = pattern_seven()
for row in result:
    print(row["marker"], row["index"], row["value"])
