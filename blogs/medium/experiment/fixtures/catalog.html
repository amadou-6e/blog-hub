Medium Telegraph Experiment Fixture Catalog

These HTML fixtures capture the source shapes we tested directly, so the next experiments can start from explicit pre-upload HTML instead of inferred Markdown conversion.

Available fixtures

  • line_break_variants.html — plain pre variants with br versus literal newlines and different blank-line handling
  • tag_variants.html — pre, pre+code, code, and plain paragraph source shapes
  • code_class_variants.html — raw and language-* classes on code nodes
  • indentation_variants.html — the long-block source shape with raw spaces, tabs, and Unicode-space indentation

Current takeaways

  • Plain pre stayed the strongest general source shape for broad pattern survival.
  • pre+code with a raw language class became important for preserving the full multiline body of the long block.
  • Visible indentation differences only started to survive when we tried wider Unicode spaces such as figure space, ideographic space, and narrow no-break space.
